# 🐵 Overlay Remover

Remove common website overlays with one click!

## 🚀 Installation

**[✨ CLICK HERE TO INSTALL OVERLAY REMOVER](https://raw.githubusercontent.com/tusar10280/overlay-remover/main/overlay-remover.user.js)**

### 📥 How to use

1. Install Tampermonkey.
2. Click the installation link above.
3. Click Install in Tampermonkey.
4. Open a website and refresh the page.
5. Click the **✖ Remove Overlay** button.

### ⚠️ Disclaimer

This script may remove legitimate website elements. Review the code before installing it.
